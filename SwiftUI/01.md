# Variáveis e Constantes em SwiftUI

O Swift é uma linguagem de programação fortemente tipada, ou seja, cada valor possui um tipo definido, como `String`, `Int`, `Double` ou `Bool`.

Em Swift, usamos **variáveis** e **constantes** para armazenar informações durante a execução do programa.

No SwiftUI, esses conceitos continuam sendo usados, mas também aparecem junto com recursos próprios da criação de interfaces, como o `@State`.

---

## 1. Declaração de Variáveis

As variáveis são usadas quando o valor pode mudar ao longo do programa.

Em Swift, declaramos uma variável usando a palavra-chave `var`.

### Sintaxe

```swift
var nomeDaVariavel: Tipo
```

Ou já atribuindo um valor:

```swift
var nomeDaVariavel: Tipo = valor
```

### Exemplo

```swift
var nome: String = "Fernanda"
var idade: Int = 20
var altura: Double = 1.65
var estaLogada: Bool = true
```

Também é possível deixar o Swift descobrir o tipo automaticamente. Isso se chama **inferência de tipo**.

```swift
var nome = "Fernanda"
var idade = 20
var altura = 1.65
var estaLogada = true
```

Nesse caso, o Swift entende que:

| Valor | Tipo inferido |
|---|---|
| `"Fernanda"` | `String` |
| `20` | `Int` |
| `1.65` | `Double` |
| `true` | `Bool` |

---

## 2. Alterando o valor de uma variável

Como uma variável foi criada com `var`, seu valor pode ser alterado.

```swift
var nome = "Fernanda"

nome = "Nanda"

print(nome)
```

Resultado:

```swift
Nanda
```

---

## 3. Declaração de Constantes

As constantes são usadas quando o valor não deve ser alterado.

Em Swift, declaramos uma constante usando a palavra-chave `let`.

### Sintaxe

```swift
let nomeDaConstante: Tipo = valor
```

### Exemplo

```swift
let nome = "Fernanda"
let idade = 20
let curso = "Engenharia Eletrônica"
```

Depois que uma constante recebe um valor, ela não pode ser modificada.

```swift
let nome = "Fernanda"

nome = "Nanda" // Erro
```

Esse código gera erro porque `nome` foi declarado com `let`.

---

## 4. Diferença entre var e let

| Palavra-chave | Significado | Pode mudar? |
|---|---|---|
| `var` | Variável | Sim |
| `let` | Constante | Não |

Exemplo:

```swift
var contador = 0
contador = 1

let nome = "Fernanda"
// nome = "Nanda" // Erro
```

Como boa prática, use `let` sempre que o valor não precisar mudar. Use `var` apenas quando o valor realmente precisar ser alterado.

## 5. Tipos de Dados em Swift

Os principais tipos de dados usados no começo do Swift são:

| Tipo | Descrição | Exemplo |
|---|---|---|
| `String` | Texto | `"Olá"` |
| `Int` | Número inteiro | `10` |
| `Double` | Número decimal | `10.5` |
| `Bool` | Verdadeiro ou falso | `true` |
| `Array` | Lista de valores | `["Naruto", "One Piece"]` |
| `Dictionary` | Conjunto de chave e valor | `["nome": "Fernanda"]` |

---

## 6. String

O tipo `String` armazena textos.

```swift
let nome: String = "Fernanda"
let mensagem: String = "Olá, mundo!"
```

Também é possível juntar textos com variáveis usando interpolação de strings.

```swift
let nome = "Fernanda"
let mensagem = "Olá, \(nome)!"

print(mensagem)
```

Resultado:

```swift
Olá, Fernanda!
```

---

## 7. Int

O tipo `Int` armazena números inteiros.

```swift
let idade: Int = 20
let quantidade: Int = 5
```

Exemplo:

```swift
let numero1 = 10
let numero2 = 5

let soma = numero1 + numero2

print(soma)
```

Resultado:

```swift
15
```

---

## 8. Double

O tipo `Double` armazena números com casas decimais.

```swift
let altura: Double = 1.65
let preco: Double = 29.90
```

Exemplo:

```swift
let preco = 29.90
let desconto = 5.0

let total = preco - desconto

print(total)
```

---

## 9. Bool

O tipo `Bool` armazena valores lógicos.

Ele só pode receber dois valores:

```swift
true
false
```

Exemplo:

```swift
let estaLogada: Bool = true
let possuiConta: Bool = false
```

---

## 10. Variáveis no SwiftUI

No SwiftUI, podemos usar variáveis e constantes normalmente dentro de uma `View`.

Exemplo:

```swift
import SwiftUI

struct ContentView: View {
    let nome = "Fernanda"
    
    var body: some View {
        Text("Olá, \(nome)!")
    }
}
```

Nesse exemplo, `nome` é uma constante, porque o valor não será alterado.

---

## 11. Variáveis que atualizam a tela com @State

No SwiftUI, quando uma variável precisa mudar e essa mudança deve aparecer na interface, usamos `@State`.

Exemplo:

```swift
import SwiftUI

struct ContentView: View {
    @State private var contador = 0
    
    var body: some View {
        VStack {
            Text("Contador: \(contador)")
            
            Button("Aumentar") {
                contador += 1
            }
        }
    }
}
```

Nesse exemplo:

- `contador` começa com valor `0`;
- ao clicar no botão, o valor aumenta;
- a tela é atualizada automaticamente.

---

## 12. Exemplo com String e @State

```swift
import SwiftUI

struct ContentView: View {
    @State private var nome = "Fernanda"
    
    var body: some View {
        VStack(spacing: 16) {
            Text("Olá, \(nome)!")
            
            Button("Mudar nome") {
                nome = "Nanda"
            }
        }
    }
}
```

Quando o botão é clicado, o texto da tela muda de:

```swift
Olá, Fernanda!
```

Para:

```swift
Olá, Nanda!
```

---

## 13. Exemplo com Bool e @State

```swift
import SwiftUI

struct ContentView: View {
    @State private var estaLigado = false
    
    var body: some View {
        VStack(spacing: 16) {
            Text(estaLigado ? "Ligado" : "Desligado")
            
            Button("Alterar estado") {
                estaLigado.toggle()
            }
        }
    }
}
```

Nesse exemplo, a variável `estaLigado` alterna entre `true` e `false`.

## 14. Identificadores

Identificadores são os nomes dados para variáveis e constantes.

Em Swift, é comum usar o padrão **camelCase**.

Exemplos:

```swift
var nomeUsuario = "Fernanda"
var idadeUsuario = 20
var mediaFinal = 9.5
```

Evite nomes genéricos como:

```swift
var x = 10
var n = "Fernanda"
var valor1 = true
```

Prefira nomes descritivos:

```swift
var idade = 20
var nomeCompleto = "Fernanda Paoleschi"
var usuarioEstaLogado = true
```

---

## 15. Palavras reservadas

Assim como outras linguagens, Swift possui palavras reservadas que não podem ser usadas como nomes de variáveis ou constantes.

Alguns exemplos:

| Palavras reservadas |
|---|
| `var` |
| `let` |
| `if` |
| `else` |
| `for` |
| `while` |
| `func` |
| `struct` |
| `class` |
| `enum` |
| `return` |
| `import` |
| `true` |
| `false` |
| `nil` |

Exemplo incorreto:

```swift
var let = "Texto" // Erro
```

Exemplo correto:

```swift
var nome = "Texto"
```

---

## 16. Nil

Em Swift, `nil` representa ausência de valor.

Mas uma variável comum não pode receber `nil` diretamente.

```swift
var nome: String = nil // Erro
```

Para permitir ausência de valor, usamos opcionais com `?`.

```swift
var nome: String? = nil
```

Depois, podemos atribuir um valor:

```swift
nome = "Fernanda"
```

---

## 17. Exemplo com Optional em SwiftUI

```swift
import SwiftUI

struct ContentView: View {
    let nome: String? = "Fernanda"
    
    var body: some View {
        Text(nome ?? "Nome não informado")
    }
}
```

O operador `??` define um valor padrão caso a variável esteja vazia.

---

## 18. Exemplo completo

```swift
import SwiftUI

struct ContentView: View {
    let titulo = "Cookbook SwiftUI"
    @State private var contador = 0
    @State private var estaAtivo = false
    
    var body: some View {
        VStack(spacing: 20) {
            Text(titulo)
                .font(.title)
                .bold()
            
            Text("Contador: \(contador)")
            
            Button("Aumentar contador") {
                contador += 1
            }
            
            Text(estaAtivo ? "Status: Ativo" : "Status: Inativo")
            
            Button("Alterar status") {
                estaAtivo.toggle()
            }
        }
        .padding()
    }
}
```

---

## Pontos-chave

- `var` cria uma variável.
- `let` cria uma constante.
- Variáveis podem ter seus valores alterados.
- Constantes não podem ter seus valores alterados.
- Swift possui tipagem forte.
- O Swift consegue inferir o tipo de uma variável ou constante.
- Em SwiftUI, usamos `@State` quando uma variável precisa mudar e atualizar a tela.
- `String` representa textos.
- `Int` representa números inteiros.
- `Double` representa números decimais.
- `Bool` representa verdadeiro ou falso.
- `nil` representa ausência de valor.
- Para permitir `nil`, usamos opcionais com `?`.
